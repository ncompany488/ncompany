# 데이터 계약: 상품 페이지·카테고리·과거 검색 (총괄 작성, 2026-11-07)

모든 파일은 `collect.py` 가 매 실행마다 `site/data/` 에 생성 (생성물, 직접 수정 금지).

## 1. 그룹에 추가되는 필드 (`deals.json` groups[*])
- `category`: 아래 목록 중 하나 (모르면 "기타")
  `식품` `생활` `가전` `디지털` `PC부품` `게임` `패션` `뷰티` `유아·반려` `스포츠·레저` `여행·티켓` `상품권·포인트` `기타`
- `product.pid`: 가격 기록의 상품 id (product 가 있고 기록에 존재할 때만, 없으면 null)

## 2. 상품 샤드 `site/data/products/<NN>.json`
- 샤드 번호: `NN = 두 자리 10진수( fnv1a32(UTF-8 pid 바이트) % 64 )`, 예 `07.json`
  - fnv1a32: h=0x811c9dc5; 각 바이트 b: h ^= b; h = (h * 0x01000193) mod 2^32
- 내용: `{ "<pid>": Product, ... }`
```
Product = {
  "name": "신라면",            // 표시용 이름
  "cat": "식품",               // 카테고리
  "basis": "개"|"100g"|"100ml"|null,  // 그래프 기준 (null = 총액)
  "unit_label": "개"|"봉"|"캡슐"|...,  // basis 가 "개" 일 때 표시 단어
  "obs": [                     // 날짜 오름차순, 상품당 최대 KEEP 개 (history 정리 규칙과 동일)
    {"d": "2026-10-01T10:00:00+09:00", "p": 15900, "u": 795 | null,   // u = basis 기준 단가 (기준이 안 맞는 기록은 null)
     "n": 20 | null, "g": 2400 | null,   // 개수, 총 용량(g/ml)
     "t": "원글 제목", "url": "https://...", "s": "ppomppu", "c": 0|1 (조건부), "e": 0|1 (종료)}
  ]
}
```

## 3. 검색 인덱스 `site/data/search.json`
가격이 있는 상품만, 최근 기록 순 정렬, 최대 20,000개:
```
[ {"id": pid, "n": "이름", "cat": "식품", "b": "개"|"100g"|"100ml"|null, "ul": "봉",
   "lu": 최저 단가|null, "lp": 그 최저 기록의 총액, "ld": "2026-10-01", "k": 기록 수}, ... ]
```

## 4. 화면
- `site/product.html?id=<pid>` : 샤드를 불러와 이름·카테고리·역대 최저(조건부 제외)·최근 가격·기록 수, SVG 가격 추이 그래프(u 기준, u 가 없으면 p), 수량별 최저가, 과거 글 전체 목록(원글 링크).
- 메인 카드의 역대 최저 영역에 `product.pid` 가 있으면 "가격 추이 보기" 링크.
- 메인 검색: 2글자 이상이면 `search.json` 을 처음 한 번만 불러와 "과거 기록에서 찾은 상품" 섹션(최대 20개) → product.html 링크.
- 카테고리 필터 칩(전체 + 위 목록 중 현재 목록에 있는 것).
